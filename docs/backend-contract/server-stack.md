# 서버 스택 권장 (Spring Boot, JDK 25)

검색으로 확인한 사실과 확인하지 못한 것을 구분했다. 버전/지원 기간은 구현 시작 시점에 공식 사이트에서 다시 확인한다.

## Spring Boot / JDK

| 항목 | 내용 | 확인 |
| --- | --- | --- |
| Spring Boot 3.5.x | 공식 시스템 요구사항: Java 17 이상, **Java 25까지 호환** | 확인 (공식 3.5 문서) |
| Spring Boot 4.0.x | 호환표: Java 17 ~ 25. 4.1은 Java 26까지 | 확인 (호환표 자료) |
| 지원 종료 | 3.5 오픈소스 지원이 2026-06-30 종료라는 자료가 있고, 다른 자료는 날짜가 4월 기준이라 최신이 아닐 수 있다 | **자료가 엇갈림** |
| 가상 스레드 | 이번 검색에서 확인하지 못함 | 미확인 |

권장: **Spring Boot 4.x + JDK 25**. 지원 기간이 길고 Java 25가 호환표에 명시돼 있다. 3.5는 지원 종료 시점이 자료마다 달라 새 프로젝트에는 권장하지 않는다. (start.spring.io에서 현재 GA를 확인.)

## TOTP 라이브러리

| 라이브러리 | 확인한 내용 |
| --- | --- |
| `dev.samstevens.totp` (java-totp) + `totp-spring-boot-starter` | Spring Boot 스타터 있음(설정: 비밀키 길이, 코드 길이, 주기, 해시 알고리즘). Maven Central 1.7(MIT). **더 최근 릴리스나 Java 25 언급은 못 찾음** |
| `com.eatthepath:java-otp` (jchambers) | GitHub 목록상 **2026-05-01 갱신**. Java/Spring 지원 정보는 못 찾음 |
| HangarMC/java-totp | Java 17+, 1.8.0, Spring Boot 스타터 있음 (포크) |
| BastiaanJansen/otp-java | 최근 커밋 논의가 오래됨 |

- **Java 25 호환을 명시적으로 확인한 라이브러리는 없다.** 이 라이브러리들은 `javax.crypto`의 HMAC만 쓰는 순수 자바라 오래된 바이트코드도 새 JVM에서 도는 것이 일반적이지만 (일반 지식), 도입 전 각 `pom`의 Java 대상과 CI를 확인하고 테스트로 검증한다.
- 권장: **`java-otp`**(최근 갱신 확인) 또는 스타터 편의가 필요하면 `samstevens`. 어느 쪽이든 **라이브러리는 코드 일치만 판정**하므로 재사용 방지(`otp_last_accepted_step`), 시도 제한, 비밀키 암호화는 직접 구현해야 한다.
- TOTP는 RFC 6238(HMAC 기반 약 30줄)이라 직접 구현도 가능하지만 검증된 라이브러리 + 테스트 벡터를 권장한다.

## 이메일

`spring-boot-starter-mail`(`JavaMailSender`) — Spring Boot 공식 스타터. (이번 검색으로 재확인하지 않은 일반 지식.) SMTP 또는 클라우드 메일 서비스를 연결한다.

## 문자 / 카카오톡(알림톡)

> **확정(사용자): 문자와 카카오는 엠엔와이즈, 메일은 Outlook으로 발송한다.** 아래 비교 표는 공급자를 정하기 전의 조사였고 참고용이다. 엠엔와이즈(Java SDK/API 방식), Outlook 발송 방식(SMTP 또는 Graph API 등)은 서버 제작 때 공식 문서로 확인한다. 이번 세션에서는 확인하지 않았다.

- 검색 결과 국내 서비스 **솔라피, NHN Cloud(Notification), 네이버 클라우드 SENS**가 모두 SMS와 알림톡을 지원한다. 어느 쪽이 "더 많이 쓰인다"는 수치는 확인하지 못했다.

| 서비스 | 확인한 내용 |
| --- | --- |
| 솔라피 | 2026 가이드가 "개발자 친화적 API, 여러 언어 SDK"로 소개. **Java SDK 존재는 공식 문서에서 확인 필요** |
| NHN Cloud | SMS/알림톡/푸시/이메일/RCS 통합. 한 블로그 기준 단가 SMS 9.9원, 알림톡 7.9원 (업체 블로그 수치, 요금표로 재확인) |
| 네이버 클라우드 SENS | 문자/알림톡/브랜드 메시지/이메일을 한 서비스로 통합 중. 기존 API·요금 유지 |

- **카카오톡 인증 = 알림톡**이다. 카카오 비즈니스 채널 개설, **템플릿 심사 승인**, 공식 파트너사 계약이 필요하고 카카오 API를 직접 호출할 수 없다 (대행사 경유). 인증번호용 템플릿을 승인받는 정책 요건은 이번에 확인하지 못했다.
- 인증번호용으로는 일반 SMS가 모든 기기에서 수신돼 주로 쓰인다는 설명이 있다.
- **권장:** 한 서비스에서 SMS와 알림톡을 모두 처리하는 곳을 하나 고르고(기존에 쓰는 클라우드가 있으면 그쪽), 코드는 `OtpSender` 인터페이스(`SmsOtpSender`, `EmailOtpSender`, `KakaoOtpSender`)로 추상화해 공급자를 바꿀 수 있게 한다. 공급자 선택은 기존 인프라/계약에 따라 결정.

## 확인할 것

1. 사용할 SMS/알림톡 공급자 (기존 계약/클라우드).
2. 인증번호 알림톡 템플릿 승인 가능 여부.
3. TOTP 라이브러리의 Java 25 동작 테스트.
4. Spring Boot 현재 GA 버전과 지원 기간.
