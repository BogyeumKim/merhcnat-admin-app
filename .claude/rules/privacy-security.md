# 개인정보 / 보안 규칙 (조직 지침)

- 개인정보를 포함하지 않는다: 실명, 이메일, 전화번호, 주소, 계정/사용자 ID, 카드·계좌 번호 등을 코드, 문서, 주석, 테스트 데이터, 커밋 메시지, 로그에 넣지 않는다.
- 예제/목업 데이터는 명백한 더미 값만 사용한다 (예: `홍길동`이 아닌 `테스트 가맹점`, `merchant-0001`).
- 비밀 값(API 키, 토큰, 인증서, `.env*`)은 커밋하지 않는다. `.env*.local`은 git 제외 상태를 유지한다.
- 이 앱은 가맹점 관리자용이다. 결제·정산 데이터는 로그에 원문을 남기지 않고, 필요 시 마스킹한다.
- 민감 값 저장은 `expo-secure-store`를 사용한다 (AsyncStorage 금지).
- 문서나 PR 설명에 사용자 개인 식별 정보를 적지 않는다.
