# 다국어 규칙 (ko / en)

- 지원 언어는 **한국어(`ko`)와 영어(`en`) 둘뿐**이다. 스택: `expo-localization` + `i18next` + `react-i18next`.
- 화면에 보이는 모든 문자열은 `useTranslation()`의 `t('key')`를 쓴다. JSX에 문자열 리터럴을 직접 쓰지 않는다 (`i18next/no-literal-string` 린트가 `src/**/*.tsx`에서 막는다).
- 번역은 `src/shared/i18n/locales/en.ts`가 기준이고, `ko.ts`는 `typeof en`으로 타입이 걸려 있어 **키가 빠지거나 남으면 컴파일 에러**다. 새 키는 두 파일에 함께 추가한다. 별도 번역 검사 스크립트는 필요 없다.
- 키는 `영역.항목` 형태 (`tabs.home`, `auth.signInTitle`). 타입이 자동완성되므로 문자열을 변수에 담을 때는 `as const`를 쓴다.
- 초기 언어: 저장된 선택 → 기기 언어(`ko`/`en`) → `ko`. 변경은 `setLanguage()`만 사용한다 (저장 + 적용).
- 사용자 이름, 계정 정보 등 개인정보를 번역 문자열이나 예시 값에 넣지 않는다.
- OS 설정의 앱별 언어 선택은 `app.json`의 `expo-localization` 플러그인 `supportedLocales`(`ko`, `en`)로 선언돼 있다. 언어를 추가하면 여기와 `SUPPORTED_LANGUAGES`, locale 파일을 함께 바꾼다.
